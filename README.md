# 📱 SQLiteApp22025

App Android hecha en Kotlin con conexión a SQLite. Este proyecto es un ejemplo funcional para la gestión de productos y categorías usando una base de datos local sin necesidad de internet. Ideal para aprender lo básico de CRUD en Android.

---

## 🚀 Características principales

- 📦 Gestión de productos (insertar, listar, actualizar, eliminar)
- 🗂️ Categorías de productos
- 🛢️ Persistencia de datos con SQLite
- 🖱️ Interfaz simple y funcional
- 💻 Hecho con Android Studio (Meerkat Feature Drop | 2024.3.2 Patch 1)

---


---

## 🛠️ Tecnologías usadas

- **Kotlin** – Lenguaje principal
- **SQLite** – Base de datos local
- **Android SDK** – Componentes nativos
- **XML** – Diseño de interfaces
- **Android Studio** – IDE usado
